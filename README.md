# Student Performance Prediction

A Machine Learning project that predicts students' Math scores based on:

- Gender
- Race/Ethnicity
- Parent Education
- Lunch Type
- Test Preparation Course
- Reading Score
- Writing Score

## Technologies Used

- Python
- Streamlit
- Scikit-learn
- Pandas
- Joblib

## How to Run

pip install -r requirements.txt

streamlit run app.py
